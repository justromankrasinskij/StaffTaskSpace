# 🇬🇧 English
## 🔎 About project
Staff Task Space is the application for managing employee tasks.

*What are the goals of this project?*  
This project has the following goals:
1. To create a unified space for all employees that allows them to conveniently manage tasks and track their completion
2. Offer an alternative to subscription-based tools - Staff Task Space is designed from the ground up as an open and free tool

<br>

*What tasks does this project solve?*  
This project solves the following tasks:
1. Convenient management of work tasks thanks to a unified space for all employees
2. Tracking employee task completion
3. Increasing the speed at which employees complete tasks by improving the consistency of their actions

# 🇷🇺 Русский
## 🔎 О проекте
Staff Task Space - это приложение для управления задачами сотрудников.

*Какие цели у данного проекта?*  
У данного проекта следующие цели:
1. Создать единое для всех сотрудников пространство, которое позволит им удобно управлять задачами и отслеживать их выполнение
2. Предложить альтернативу инструментам, которые распространяются по подписке - Staff Task Space с самого начала разрабатывается в качестве открытого и бесплатного инструмента

<br>

*Какие задачи решает данный проект?*  
Данный проект решает следующие задачи:
1. Удобное управление рабочими задачами благодаря общему для всех сотрудников пространству
2. Отслеживание выполнения сотрудниками задач
3. Увеличение скорости выполнения сотрудниками задач за счет улучшения согласованности их действий
